# 訪日客に接する「日本側の主体」の需要調査 — B2B ピボットの妥当性

> 調査日: 2026-08-19
> 起点: [inbound-disaster-needs-2026.md](./inbound-disaster-needs-2026.md) の「災害時に役立った情報源1位 = 宿泊先の従業員（30.3%）」。
> 情報が日本側の主体を経由して届いているなら、買い手はその主体ではないか、という問い。
> 対象読者: 本プロジェクトの事業形態（誰に届け、誰が費用を負担するか）を決める人

---

## 要約

1. **需要は実在する。ただし「宿に直接売る」形では成立しにくい。** 宿泊施設向けの災害時多言語機能は、既に talkappi（導入 2,200 施設超）が **CHATBOT 利用施設へ無料で** 提供済み。宿泊業のIT予算は PMS・予約系に向いており、防災は「補助金がついたときだけ動く」領域である。
2. **最も硬い需要は宿ではなく「外国人を雇う側」にある。** 特定技能の義務的支援には「生活オリエンテーション（**8時間以上**・**外国人が理解できる言語**・**防災を含む**）」が制度として組み込まれている。登録支援機関は **10,300 件超**、支援委託費は **月額平均 28,386 円/人** ＝ 既に金が動いている商流に隣接する。
3. **自治体は「買って配る」主体として実在する。** 東京都・福岡県は宿泊施設向け多言語コールセンターを **自治体負担で無料提供**している。同じ構造（B2G2B）なら、宿の予算を当てにせずに宿へ届く。
4. **ただし本リポジトリは PUBLIC + MIT。** コードそのものは売り物にならない（誰でも clone してビルドするのが正規の権利）。売れるのは **運用・継続更新・責任・研修** だけである。価格を議論する前にここを確定させること。

### この調査の限界（先に明示する）

- セグメントごとの「支払い意思」を **直接示す調査には到達していない**。以下は制度上の義務・既存商流の単価・自治体の実例から**推論**したものであり、ヒアリング等の一次検証は未実施。
- 宿泊事業者・登録支援機関への**実地ヒアリングはゼロ**。数字はすべて公開統計と公表資料に基づく。

## 0. 前提の確定 — 何を売るのかは配布形態が決める

```
gh repo view --json visibility,licenseInfo
→ {"visibility":"PUBLIC","licenseInfo":{"key":"mit"}}
```

MIT ライセンスの公開リポジトリでは、第三者が clone してビルドし、商用利用・再配布することが**明示的に許諾されている**。したがって:

| 売れないもの | 売れるもの |
|---|---|
| アプリ本体・16言語の辞書・ソースコード | **稼働している URL の運用**（可用性・更新・障害対応） |
| 買い切りライセンス | **継続更新の責任**（警報種別・地域コードの追随） |
| 機能の独占提供 | **導入設計・研修・マニュアル整備**（人が介在する部分） |

「public にして発見されやすくする」と「コードを売る」は両立しない。無料公開を継続するなら、収益は**役務**に置く。

## 1. 市場規模（一次統計）

| 対象 | 規模 | 時点・出典 |
|---|---|---|
| 訪日外国人旅行者 | **4,268万人** / 旅行消費額 **9.5兆円** | 2025年、JNTO・観光庁 |
| 在留外国人 | **412万人**（総人口比 3.3%） | 2025年末、出入国在留管理庁 |
| 外国人労働者 | **257万人**（雇用者全体の約4%） | 2025年10月末、厚生労働省 |
| 宿泊施設 | **98,338施設**（旅館・ホテル営業 52,946 / 簡易宿所 44,901） | 令和6年度末、衛生行政報告例 |
| 登録支援機関 | **10,300件超** | 2025年6月 |

**重要な非対称**: 訪日客 4,268万人は「一過性の通過者」で課金接点がない。在留外国人 412万人・外国人労働者 257万人は**雇用主という支払い主体が紐づいた常設の対象**である。同じ多言語防災でも、後者には制度的な支払い原資がある。

## 2. セグメント別の需要と障壁

### A. 宿泊施設（ホテル・旅館） — 需要は本物、支払いは弱い

| 観点 | 内容 |
|---|---|
| 困りごと | 災害時、外国人客への情報提供が従業員に集中する。訪日客側の調査では **「災害情報の提供があり理解できた」49.5%**、**「提供は無く自分で探した」31.3%**（2019年10月・観光庁検討会） |
| 制度的な後押し | 観光庁「自然災害発生時の訪日外国人旅行者への初動対応マニュアル策定ガイドライン」（2014年10月）、および「観光危機管理計画等作成の手引き」（2022年3月、**事業者向け分冊あり**）。ただし**いずれも努力義務であり罰則を伴う法的義務ではない** |
| 支払い原資 | 観光庁の受入環境整備補助金（多言語対応が補助対象）。2026年度の観光庁予算は約1,383億円という報道あり（**二次情報。一次確認が必要**） |
| 既存の代替 | **talkappi「災害時モード」= CHATBOT 利用施設に無料**。導入 2,200 施設超、初期費用0円〜の定額制 |
| 障壁 | 平常時に価値が出ない機能に月額を払う動機が薄い。人手不足が最優先課題であり、防災は後回しになりやすい |

**評価: 単独での直販は薄い。** ただし「宿に届ける」こと自体は目的として正しい（役立った情報源1位）。届け方を課金と分離すべき。

### B. 外国人を雇う企業・登録支援機関 — 法定の義務＋既存商流（最有力）

| 観点 | 内容 |
|---|---|
| 制度的な義務 | 特定技能1号の**義務的支援10項目**に「生活オリエンテーション」が含まれ、**8時間以上**・**外国人が理解できる言語**で実施し、内容に**防災・緊急連絡先**を含むことが求められる |
| 別系統の義務 | 労働安全衛生法59条の安全衛生教育について、外国人雇用管理指針は「**母国語等を用いる、視聴覚教材を用いる等、当該外国人労働者がその内容を理解できる方法により**」実施するとする。日本語のみの教育は禁止ではないが、**理解が不十分なら安全配慮義務違反を問われうる**（＝コンプライアンス費用として予算が立つ構造） |
| 市場 | 登録支援機関 10,300件超、**支援委託費 月額平均 28,386円/人**（3万円以下が約9割） |
| 既存の代替 | 自治体・CLAIR・内閣府の無料多言語防災資料（内閣府「外国人のための減災のポイント」は15言語＋QR）。**ただしこれらは静的な資料であり、実災害時のリアルタイム情報ではない** |
| 障壁 | 買い手は「防災ツール」ではなく「支援業務の履行証跡」を欲しがる。単体アプリではなく**実施記録・多言語教材・確認テストまで含めた形**でないと刺さらない（推測） |

**評価: 最有力。** 理由は3つ — ①義務が制度で明文化されている ②月2.8万円/人の支払い実績がある ③対象が**常設**（在留者は毎年入れ替わりながら継続的に発生する）。

### C. 自治体・DMO — 予算はあるが調達の壁

| 観点 | 内容 |
|---|---|
| 実例 | **東京都**が宿泊施設向け多言語コールセンターを提供、**福岡県**が「ふくおかよかとこコールセンター」を24時間365日・**通訳料無料**で提供。いずれも自治体が費用を負担し事業者に無料で配る形（B2G2B） |
| 制度 | 観光庁「観光危機管理計画等作成の手引き」に**自治体・DMO向け分冊**があり、DMO は観光地域づくり戦略に観光危機管理を組み込むことが期待されている |
| 既存の代替 | CLAIR「災害時多言語支援の共通ツール」（2025年8月に v2.0 更新）、出入国在留管理庁の外国人生活支援ポータル。**無料で配られている** |
| 障壁 | **個人事業主にとって調達要件（法人格・実績・体制）が現実的な壁**。年度予算のサイクルが遅い（提案から入金まで1年前後は珍しくない） |

**評価: 単価は最も高いが、いまの体制では取りにくい。** 実績づくり（自治体1件の無償導入事例）を先に置く順序でしか入れない。

### D. 未調査のセグメント

学校・大学（留学生）、交通事業者・空港、商業施設、医療機関、外国人向け不動産・寮運営。**本調査では未着手**。B が有望と出たため優先度を下げた。

## 3. 競合の現況

| 種別 | 主体 | 価格 | 本プロジェクトとの差 |
|---|---|---|---|
| 宿泊施設向けSaaS | talkappi（災害時モード） | CHATBOT 利用施設に**無料** | talkappi は**施設が手動で編集・公開**する運用。気象庁/P2P からの**自動取得ではない**（本プロジェクトの差別化点になりうる） |
| 公的アプリ | 観光庁 Safety tips | 無料・15言語 | 認知度・DL数の公的データは**確認できていない**（「使われていない」とは主張できない） |
| 公的資料 | 内閣府「外国人のための減災のポイント」 | 無料・15言語＋QR | 静的なポスター/PDF。リアルタイム性なし |
| 公的ツール | CLAIR 災害時多言語支援共通ツール | 無料 | 支援センター運営の手引きと定型文。個人向け配信ではない |
| 有料役務 | 多言語コールセンター各社（ベルシステム24、テレコメディア、NTT ProCX 等） | 月額制（**具体的な価格は非公開**） | 人力の通訳。24時間365日。**実際に金が動いている領域はここ** |

**読み取れること**: 無料で飽和しているのは「情報・コンテンツ」であり、金が動いているのは「**人が介在する役務**（通訳・支援委託・研修）」である。本プロジェクトの資産（自動取得＋16言語＋行動指示）は単体では無料側に属する。**役務と束ねたときにだけ値段がつく。**

## 4. 推奨する順序

### 第1段: 公開URLを作る（課金と切り離す）

すべての前提。QR・印刷配布・自治体への提案・実績づくりのどれも、**稼働しているURLがないと始まらない**（[requirements-gap-2026.md](../dev/requirements-gap-2026.md) 項目7 で「着手不可」としていた理由）。無料・PWA・広告なしで公開する。

### 第2段: 宿泊施設への無償配布で実績を作る

第一読者は**宿の従業員**（役立った情報源1位30.3%）。売るのではなく、館内掲示1枚＋QR で配る。狙いは収益ではなく **導入事例と利用実績**（第3段の入場券）。

### 第3段: 収益は「外国人を雇う側」に置く

生活オリエンテーション（防災パート）の**実施を支援する形**に載せ替える。単体アプリではなく、多言語教材＋実施記録＋更新の継続を役務として売る。想定単価は既存商流（月2.8万円/人）の**一部を代替する水準**に置く（具体額は未検証）。

### 第4段: 自治体・DMO は実績が揃ってから

補助金と予算はここにあるが、順序を飛ばすと調達要件で落ちる。

## 5. 断定しないこと（未検証）

- **支払い意思の直接的な証拠はない。** 制度上の義務と既存商流の単価から推論している。ヒアリング1件も実施していない。
- 観光庁2026年度予算「約1,383億円・前年比2.4倍」は**二次情報**。補助金の対象要件（ソフトウェアが対象になるか）は未確認。
- 宿泊施設数 98,338 の内訳は**二次情報経由**。一次は厚労省「令和6年度衛生行政報告例」。
- talkappi 以外の宿泊施設向け防災SaaS は網羅的に調べていない。
- 「宿の従業員が情報源1位」の根拠は 2018年・n=185・単一事象の調査1本のまま（[inbound-disaster-needs-2026.md](./inbound-disaster-needs-2026.md) の限界をそのまま引き継ぐ）。
