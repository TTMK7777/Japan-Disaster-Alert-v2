# 訪日外国人の災害時ニーズ調査 — 公的調査の棚卸し

> 調査日: 2026-07-30
> 目的: 訪日外国人が災害発生時に実際に困ったこと・求めたことを、公的資料に基づいて特定する
> 対象読者: 本プロジェクトの機能優先度を決める人

---

## 要約

1. **災害時の訪日客ニーズを数値で押さえた調査は事実上1本しかない。** 観光庁が検討会の公式資料として採用した 2018 年の北海道胆振東部地震調査（n=185）。困ったこと1位は **停電で情報が取れない／充電できない（67.0%）**、ニーズ1位は **充電ポイントの提供（50.8%）**。
2. **観光庁の毎年の定期調査（最新 = 2026年4月公表, n=4,110）には災害項目が1つも無い。** 平時の受入環境しか調べていないため、災害時のインバウンドは公的統計の空白地帯である。
3. **SNS は最大のリスク要因でもある。** 2025 年、漫画由来の「7月5日大災害」デマが SNS で拡散し、訪日香港人が 6 月に前年比約 33% 減。一方 JNTO の SNS 発信は **英語・中国語の2言語のみ**。

### この調査の限界（先に明示する）

数値の土台は **2018年・n=185・単一事象・札幌の観光案内所での対面調査** 1本である。これより新しい同等の公的調査は発見できなかった。以降の機能判断はこの制約を前提にすること。

## 4. 実際に役立った情報の入手先（同調査）

| 入手先 | % |
|--------|---|
| 宿泊先の従業員 | 30.3 |
| ツアーコンダクター | 25.4 |
| **日本にいる外国人の SNS の書き込み** | 23.8 |
| 母国の WEB サイト | 22.7 |
| 同行の日本語ができる人 | 17.3 |
| 日本のテレビ・ラジオ | 16.8 |

**公式チャネルが上位に1つも入っていない。** 実際に効いたのは「人」と「SNS」だった。

## 5. 事前準備の欠落（同調査）

- 宿泊施設到着時に避難の事前説明が **「なかった」67.5%**（あった 19.6%）
- 宿泊施設の避難誘導が **「あり、理解できた」25.8%** ／「あったが日本語で理解できなかった」12.3%

→ 対象ユーザーは **災害が起きてから初めて防災情報に触れる**。事前インストール・事前設定を前提にした設計は届かない。

---

## 6. 公的に認定されている構造的課題（観光庁 中間報告）

- 気象情報・交通情報は主体ごとに発信されており **「一元的に把握できない」**
- 多言語の発信手段（SNS やアプリ）はあるが、**「確実に届く手法や周知」の不断の見直しが必要**
- 国の方針は一貫して **「情報入手手段の多重化」**（2018 年の緊急対策以降）

## 7. 現行の公式ツールと言語カバレッジの断層

| ツール | 主体 | 対応言語 |
|--------|------|---------|
| Safety tips（アプリ） | 観光庁監修 | **15言語** |
| Japan Safe Travel（X / Weibo） | JNTO | **2言語のみ** |
| Japan Safe Travel Information（Web） | JNTO | **英語のみ** |
| Japan Visitor Hotline | JNTO | 4言語 |
| NHK WORLD-JAPAN | NHK | 英語 |
| Safety Information Card | 観光庁 | 4言語 |

プッシュ通知は 15 言語なのに、**SNS は 2 言語、Web は英語だけ**。ここが本プロジェクトの入り込みどころである。

## 8. SNS 由来のデマが実害を出している（2025年）

- 漫画の「2025年7月5日に大災害」予言が SNS で拡散
- 訪日香港人: 5月 前年比 **約11%減** → 6月 **約33%減**（6月実数 16.7万人）
- 気象庁は「日時を特定して災害を予測することは科学的に不可能」と明言、JNTO 香港事務所が正確な情報発信で対応

→ SNS 発信は集客手段であると同時に、**デマに対する反証を、デマと同じ速度・同じ言語で流す防衛装備**として位置づけられる。

---

## 9. 裏取りできなかったこと

- **Safety tips の認知度・ダウンロード数の公的データは見つからなかった。** 「使われていない」という主張は現時点で裏付けられない。
- 内閣府 ESRI Working Paper No.59（首都直下地震シナリオでの訪日客避難行動）は PDF が文字化けし内容未確認。
- 2019 年以降、胆振東部地震調査に相当する規模の災害時・訪日客向け公的調査は発見できなかった（無いとは断定できない。探索範囲で見つからなかった、が正確）。
